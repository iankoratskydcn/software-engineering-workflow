How to read this

Start with context to see actors and system boundaries. Move to containers for runtime responsibilities, then inspect the desktop plugin's internal components.

  • Solid relationships show current code-backed paths.
  • External systems are intentionally kept at boundary level.
  • The telemetry service is read-only from the desktop pane.
